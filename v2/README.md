# Jia’s room — v2

The original room remains the subject. V2 preserves the pale wood twin bed, purple blanket, white duvet, window desk, laptop, keyboard, tablet, headphones, black slatted rolling chair, four-drawer dresser, white sliding closet, blue diffuser, mushroom lamp, pink bunny, cream bag, tissue box, coral case and framed postcards.

Additions are limited to sparse trailing vines, three small hanging stars, a tiny windowsill plant and a compact muted rug. Warm lighting and a soft sage backdrop borrow the mood of the reference without replacing the user’s belongings. V1 is unchanged.

## Preview

Put this folder at ~/Documents/jias-room-v2, then run in a separate Terminal tab:

```sh
python3 -m http.server 5174 --bind 127.0.0.1 --directory "$HOME/Documents/jias-room-v2"
```

Open http://127.0.0.1:5174. Internet and WebGL are required. Keep the server running. This is a procedural Three.js model; browser rendering has not been verified in this workspace.
